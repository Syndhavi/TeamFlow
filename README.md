
# TeamFlow

A collaborative project and task management platform.

## Overview

TeamFlow helps organizations manage workspaces, projects,
team members and tasks through a centralized application.

## Technology Stack

- React
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Prisma

## Project Status

Currently in the requirements and system design phase.

## Development Approach

The project is being developed independently using a
modular monolithic architecture.

## Repository Structure

- client/ - Frontend application
- server/ - Backend application
- docs/ - Project documentation
